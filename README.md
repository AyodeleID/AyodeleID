| Task | Methods | Winner | Key Result |

### ⚽ EPL 2025–26 Season Outcome Forecasting

[![Repo](https://img.shields.io/badge/Repo-epl--forecast--2025--26-0f3460?style=flat-square&logo=github)](https://github.com/AyodeleID/epl-forecast-2025-26)
![Domain](https://img.shields.io/badge/Domain-Sports%20Analytics-e94560?style=flat-square)
![Language](https://img.shields.io/badge/Language-Python-3776AB?style=flat-square&logo=python&logoColor=white)

> Predicts H/D/A probabilities and most-likely scorelines for all **380 Premier League fixtures** in 2025–26.

| Field | Details |
|-------|---------|
| **Model** | Dixon–Coles Poisson with time-decay & low-score correction |
| **Training data** | PL results 2022/23 – 2024/25 (football-data.co.uk) |
| **Fixtures** | football-data.org API (PL 2025 season) |
| **Output** | `predictions_epl_2025_26.csv` — Date, Teams, P(H/D/A), Most-Likely Score, Tip |
| **Coverage** | All 20 clubs including promoted teams (initialised at league-average strength) |

```python
# Quick coverage check
import pandas as pd
df = pd.read_csv("predictions_epl_2025_26.csv")
len(df), df["HomeTeam"].nunique()   # → (380, 20) ✅
```
